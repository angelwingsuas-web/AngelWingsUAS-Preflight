# AngelWingsUAS Preflight

A mobile-friendly, GitHub Pages-ready drone preflight checklist using the official supplied AngelWingsUAS logo.

## Features

- 24-point safety checklist
- Mission and pilot information
- Live ready/not-ready status
- Automatic saving on the current device
- Print-friendly layout
- Offline/installable web app support
- Responsive phone, tablet, and desktop design

## Publish with GitHub Pages

1. Unzip the downloaded package.
2. Upload everything inside the folder to the root of your `AngelWingsUAS-Preflight` repository. Keep the `css`, `js`, and `images` folders intact.
3. Commit the files to the `main` branch.
4. Open **Settings → Pages** in the repository.
5. Choose **Deploy from a branch**, select **main** and **/(root)**, then save.
6. The site will normally appear at `https://YOUR-USERNAME.github.io/AngelWingsUAS-Preflight/`.

Checklist data stays in the browser on the current device. This app supports planning but does not replace FAA rules, manufacturer guidance, local requirements, or the remote pilot's responsibility for safe operation.
